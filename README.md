# Web RTS

Браузерная multiplayer RTS до 4 игроков с режимами Solo, Coop и PvP/PvPvE.

Проект находится на стадии продуктового и технического проектирования. Разработка планируется через spec-first и agent-driven workflow: требования → спецификация → реализация → автоматические тесты → review → playable build.
